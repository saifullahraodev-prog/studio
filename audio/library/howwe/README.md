# How We Ended Up: music + SFX from the YouTube Audio Library (free)

Put downloaded tracks here. Name them `<mood>-<original-title>.mp3`, e.g. `curious-Sunny Afternoon.mp3`.
For every file, add a row to `audio/LICENSES.md` (title, artist, "YouTube Audio Library", licence type,
attribution needed yes/no, date downloaded). Only use files downloaded from YouTube Studio's own Audio Library page.

Wanted for the first videos (2-3 tracks to start):
- curious bed: questions, exhibits, map (light, warm, 80-100 bpm, no vocals)
- soft bed: history / period rooms (calm piano or strings)
- sparse bed: the reveal (minimal, ambient)
