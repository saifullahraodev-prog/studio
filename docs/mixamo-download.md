# Mixamo downloads (owner does this; ~15 minutes)

Mixamo is Adobe's free motion-capture library. It needs a free Adobe account, which only you can create,
so you download and I wire the files in. Mixamo's terms allow royalty-free use in videos (we never
share the raw files).

Put every downloaded file in: **`D:\Claude Workflow\studio\public\models\mixamo\`**
(or leave them in Downloads and tell me; I'll move them).

## 1. Sign in
Go to https://www.mixamo.com and sign in (or create a free Adobe account).

## 2. The body (download once)
1. Click the **Characters** tab.
2. Type **soldier** in the search box. Pick a soldier in a plain uniform (no sci-fi armour).
   If none looks right, pick **Y Bot** (plain grey mannequin); I'll colour and dress it.
   Our cartoon head replaces its head either way, so the face doesn't matter.
3. Click **Download**: Format **FBX Binary (.fbx)**, Pose **T-pose**. Save it as **`body.fbx`**.

## 3. The moves (one file each)
Keep the same character selected. Click the **Animations** tab, search the name, click the result
that matches, then:
- If there's an **In Place** checkbox on the right, **tick it**.
- Click **Download**: Format **FBX Binary (.fbx)**, Skin **Without Skin**, Frames per Second **30**,
  Keyframe Reduction **none**.
- Save with the file name in the right column.
