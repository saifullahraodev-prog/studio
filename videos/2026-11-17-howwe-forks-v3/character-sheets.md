# Character reference sheets (storyboard v2)

Generate these **before any scene**. Approve one image per sheet, save it as `refs/<SHEET ID>.png` in this folder, and use it as the character or image reference for every scene that character appears in. That is what keeps 83 generations looking like one documentary.

Every prompt uses the same character description as the scene prompts, word for word, plus the channel style block.


## Review checklist (for each sheet before approving)

- Same face in all three views: eyes, nose, jaw and hairline don't drift.
- Clothing matches the description exactly (colours, collar, sleeves, accessories); nothing invented, no costume stereotypes.
- Hands: five fingers each; utensils held the right way (chopsticks between thumb and fingers, not fists); right versus left hand as written.
- Age reads correctly (grandparents look their age, children look like children).
- Style: charcoal outlines, flat muted colours, paper grain, cream background; not glossy, not 3D, not anime.
- No text, logos or watermarks.

## Sheets

24 people + 2 variants. 'Appears in' lists storyboard v2 scene numbers.
